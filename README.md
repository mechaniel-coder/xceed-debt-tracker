# Xceed debt tracker

Single page, `index.html`. It shows wages and the California waiting-time penalty for Daniel Pall v. jonxt.3xbtc / X-CEED Tech Solutions LLC.

The figures are not a frozen export. The page computes them in the browser:

- Base wages: $2,261.78
- Daily penalty: $270.40
- Termination: May 29, 2026, 2:55 AM
- Penalty stops after 30 days (June 28, 2026) at $8,112.00

Equity (30%) and commission (7%) are named on the page and are not included in the running total.

Open `index.html` in a browser. There is no build step and no backend.
